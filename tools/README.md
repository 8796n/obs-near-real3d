# tools

開発・検証用の補助。配布物には含まれない。

## `export_onnx.py` — 深度モデルの ONNX 書き出し

Depth Anything V2 Small を ONNX 化して `models/depth_anything_v2_small.onnx` を生成する。
既定は **FP16・固定形状**で、出荷モデルと同じ **16:9 の 448×252**。

```bash
python tools/export_onnx.py                          # 448x252 (16:9), FP16 (現行同梱)
python tools/export_onnx.py --width 392 --height 392 # legacy 正方
python tools/export_onnx.py --no-fp16                # FP32 グラフ
```

要 `torch` / `transformers` / `onnx` / `onnxruntime`（FP16 は CUDA）。入力は 14 の倍数なら任意の W×H 可。
別寸にしたらプラグインの `INFER_W`/`INFER_H` も合わせること（不一致だと推論が要素数不一致で輝度フォールバックになる）。

## `avsync_test.html` — A/V 同期テストパターン

### 何のため
`Frame-matched depth`（`sync_delay`）は、映像を遅延リングで `applied_d` フレーム遅らせ、**親ソースの音声同期オフセット**を同じだけ動かして A/V を保つ。
「音が途切れない」こと自体は正常動作の証明にならない（オフセットが未適用でも途切れない）。壊れている場合の症状は**途切れではなく「音が映像より ~0.1 秒先行する」**。
この機能は detach/Undo/非表示/無効化/スレッド安全で多くの修正を経ているため、**回帰を繰り返し確認できる**手段としてこのテストパターンを置く。

### 何が映るか
- 1 秒ごとに**ビープ**、その瞬間に赤い**スイープバーが緑の中央線「0 (beep)」にちょうど乗り**、白い**リングが発光**する。
- 中央線まわりに **±ms 目盛り**（周期 1 秒なら概ね 1px ≈ 1ms）。ズレを ms で読める。
- 下部に**実音声のスクロール波形**（ビープが周期スパイクで出る）。
- ビープ（音）とバー位置（映像）は同一の Web Audio クロックで駆動するので、**ソース側では厳密に一致**している。よって OBS 出力で見えるズレはフィルタ（または OBS の音声経路）由来。

### 手順（OBS）
1. まずブラウザで直接開いて確認（クリックで音有効化 → ビープ時にバーが緑線上＝ソースは同期 OK）。
2. OBS: ソース＋ → **ブラウザ** → ローカルファイルで `tools/avsync_test.html`、サイズ 1920×1080、**「OBS で音声を制御」を ON**（ページ音声をソース音声に載せる＝フィルタの sync offset 対象になる）。
3. そのソースに **near Real 3D (SBS)** を適用。
4. **Frame-matched depth OFF**（基準）: ビープ時にバーは緑線上。
5. **Frame-matched depth ON**: 映像も音声も同じだけ遅れる設計なので、**ON でもビープ時にバーが緑線上／リング発光**のままなら A/V 同期維持＝正常。
   音だけ未遅延（不具合）なら、ビープが鳴った時にバーが緑線より**左**におり、その差を ±ms 目盛りで読める（≒実測レイテンシ ~100ms）。
   - SBS 出力で左右 2 分割になるが、**どちらか片眼**を見れば判定できる（バーと中央線は同じだけ warp されるので一致関係は保たれる）。

### クロスチェックと期待値
- ソース右クリック →「オーディオの詳細プロパティ」の**同期オフセット**を見る。
  - **ON**: ウォームアップ後に **+100ms 前後**（実測レイテンシ ≒ 数フレーム）。実機で **+99ms** を確認済み。
  - **OFF / 無効化 / フィルタ削除 / 別シーンへ移動**: 元値（通常 0）へ戻る。戻らなければ同期オフセットのリーク（要調査）。
- 音声**トラックのあるソース**で試すこと（画面キャプチャ等の無音ソースは当然「途切れない」だけになる）。

### 備考
- ブラウザソースで音が出ない場合（CEF の autoplay 制限）は「対話」ウィンドウで一度クリックするか、Media Source 用の動画版を別途用意する。
- キー操作（フォーカス時）: ↑/↓ でビープ周期、Space で音声再開。
